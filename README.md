# Hi, I'm Justin 👋

I'm a software developer in Berlin. Outside work, I build tools for reading in other languages, especially German, Greek, and Italian. I enjoy experiencing literature, history, folktale, and myth through primary sources.

### Currently building

**[Mouseion](https://github.com/justin-hayes/mouseion)** is a self-hosted reading environment for learning foreign languages. You read real books, and NLP analysis turns them into vocabulary you can study. It's built with Go, Python/Stanza, and PostgreSQL, and supports German, Italian, and Greek.

**Coming soon:** a digital scholarly edition of Gustav Schwab's *Die schönsten Sagen des klassischen Altertums*. It builds on the TEI XML from the Deutsches Textarchiv and adds a model of mythological figures linked to Wikidata.

### Earlier projects

- **[ellada-api-nest](https://github.com/justin-hayes/ellada-api-nest)** is a NestJS API over a subset of the Metropolitan Museum's collection data, with a **[Vue/Nuxt frontend](https://github.com/justin-hayes/ellada-ui-nuxt)**.
